## 🤖 Agentic Systems

Agents are a big part of how I work now, both building them and using them to ship faster.

| Agent | What it does | Stack |
|---|---|---|
| 🔎 **Log triage agent** | Reads application logs and events, identifies likely issues, and opens a GitLab MR with a suggested fix | LangGraph · Langfuse · GitLab CI |
| 📝 **Documentation agent** | Runs after each successful production deployment and opens an MR with updated technical docs | LangGraph · GitLab CI |
| 🏗️ **Architecture advisor** | Helps early-stage AI product teams design async, event-driven, fault-tolerant systems with observability built in | AWS · Terraform · CI/CD |

**How I build them**
- **Idempotent by default.** Every run can be retried safely, and state lives in a flexible-schema store.
- **Traceable.** Every agent step is logged in Langfuse, so failures can be debugged, not guessed at.
- **Human in the loop.** Agents propose changes as merge requests. People review and merge.
